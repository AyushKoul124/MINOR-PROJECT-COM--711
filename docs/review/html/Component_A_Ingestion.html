Component A — Ingestion

How public Telegram posts get into the database, and how the demo still works offline.

This brief is for the teammate who presents collection. The exam path is the offline seed. Live Telegram is extra and can fail on campus Wi-Fi or Telegram rate limits.

1. What this agent does

Component A collects public Telegram posts and stores them once. It does not decide whether a post is positive, topical, or coordinated. It only records the message, the channel, the time the message was posted, and any photo that was saved.

The National Technical Research Organisation name is the origin of the public problem statement. This software is an undergraduate prototype. It is not an operational intelligence system.

4. How a live pull works

  1. One worker only. A second client would lock the Telegram session file.
  2. Channels are read with a pause and a small random wait, so Telegram is less likely to block the account.
  3. If Telegram returns a flood wait, the client sleeps for the time Telegram demands, then continues.
  4. Each saved row uses posted_at for the message time. ingested_at is only when our program stored it. Later agents must use posted_at.
  5. If the same message is imported again, the text time is kept. Photos and reaction counts can be updated.

Figure 2. A new post is stored as pending. Component B is the only agent that later marks it processed.

6. What to show

Open Sources. It lists channels, how many posts are saved, and the last check. Say: “Collection writes rows. It does not analyse them.” Then show one photo path if a reviewer asks where images go: the Telegram Desktop folder, with the path also stored on the post.

One sentence. “We store the public post and the time Telegram gave it. Analysis is a later step, so a dead network cannot erase the demo.”

9. Likely questions

QuestionAnswer
Why not the download time?Download time measures our delay. Topic speed and coordination use posted_at.
Why one worker?The Telegram session file is a single SQLite file. Two workers corrupt or lock it.
Why did a live run stop?Telegram asked the account to wait. The client sleeps. That is rate limiting, not a crash.
