Second review · academic prototype · not an operational system

The whole project, in plain words

One pass from a saved post to the seven pages, written so any teammate can explain it.

Read this once before the review. The five agent briefs and the stack brief have the detail. This page is the story you tell if you only get a few minutes.

1. What we built

We built a small system that reads public Telegram posts and turns them into a dashboard. It shows how the wording feels, who seems to be speaking as a group, which themes are speeding up, and which accounts sit close together in the conversation. A person can also ask a question, and the answer has to come from those summaries.

It is a student prototype for a second review. It is not a finished intelligence product. It does not watch private chats, and it does not decide that a person is a bot or that a campaign is real.

2. The idea in one breath

Save the post. Read the post. Then look across many posts at once. The first step is storage. The second step is one post at a time. The third step is a time window, usually the last 48 hours, using the time Telegram put on the message. The clock on our download does not count, because that clock only measures how late we were.

Figure 1. Four steps. Nothing on the right is allowed to invent a fact that the left-hand steps did not write down.

3. The five jobs

CollectionPut the public post in the database, once. Mark it as waiting.Sources

The first page, Overview, is only the counts: how many posts are saved, how many are still waiting, and the latest window. Ask is the last page. It is not a sixth analysis. It searches the short notes the other jobs already wrote.

4. What happens when someone clicks Run analysis

  1. Take waiting posts that have words. For the review button, stop at 50 so the machine can finish.
  2. Read them one model at a time. The graphics card has 4 GB, so the models cannot all sit in memory together. A photo with no caption is skipped.
  3. Mark those posts as done.
  4. Recompute the audience, the themes, and the graph for the time window.
  5. Write short summaries. Ask can search those summaries afterwards.

A post that was just downloaded does not appear on Sentiment until this run has read it. Collection and reading are different steps on purpose. If the network drops, the saved posts are still there.

Figure 2. The button does not download anything. It only reads posts that are already saved.

5. Where a post can come from

For the review, use the prepared seed. It needs no internet. The same tables can also hold a Telegram Desktop export, or a live read of public channels on our subjects. The live read keeps the latest 80 messages and any photos, and Telegram can pause it for a long wait. That is why the live read is optional. All three sources become the same kind of row. The message time stays the message time.

6. How a question is answered

Ask does not browse the raw posts and guess. It turns the question into numbers, finds the nearest short summaries, and stops if even the nearest one is a poor match. Only then does a language model write a paragraph from those summaries. The question and the summaries are stored, so we can show what the answer was based on.

Say this. “If the search finds nothing close, we would rather show no answer than a fluent invention.”

7. A two-minute walkthrough

  1. Open Overview. “These are saved posts and posts still waiting to be read.”
  2. Open Sources. “Collection only stores. It does not judge the text.”
  3. Open Sentiment. “The bars are the wording. The reaction row is people tapping emoji. Sarcasm warns us. It does not flip the label.”
  4. Open Audience. “This is a sketch of the group. If the count is under 50, say it is below our privacy line.”
  5. Open Trends. “This cluster is arriving faster in the second half of the window. The words are extracted, not a headline we wrote.”
  6. Open Network. “Lines are forwards, replies, and mentions. A mark at 0.70 is a screen, not an accusation.”
  7. Open Ask. Ask one prepared question. Point at the passages under the answer.
