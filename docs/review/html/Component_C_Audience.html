Component C — Audience

How the prototype describes a group of accounts without profiling a person.

This brief is for the teammate who presents audience. The output is a coarse guess from public text and posting time. It is not a census.

1. What this agent does

Component C summarises who appears to be talking in a time window: rough age bands, rough region, language, interests, and when posts arrive in India Standard Time. It works on groups. It does not open a page for one named person and assign them an age.

2. Where it sits

Figure 1. Posts land in Postgres. B reads one post at a time. C, D, and E recompute a time window. Ask searches the short summaries those agents write.

C runs on a window, usually 48 hours of posted_at. It recomputes that window. It does not update one account in place all day.

3. Two layers

LayerWhat is visibleWhat we infer
BroadcastChannel name, topic tags, hours when posts appearA coarse interest and a daily rhythm
DiscussionPublic display name and bio text of people who spoke in a linked discussionKeyword hints for age band, region, and interest

Telegram does not give us a subscriber list. Anyone who never speaks is invisible. Say that before a reviewer treats the chart as the whole audience.

4. The privacy line

The locked rule is k-anonymity with k at least 50. A group smaller than 50 accounts is marked below_threshold. The production guard uses 50. A demo run can use 15 so a small seed still produces a card. The card must be described as below the research threshold, not as a reliable demographic.

The current Audience page can show a small group because a demo run saved one. In the review, say the guard exists and the number on screen is below 50, so it is illustrative, not a finding about a population.

5. What is written

FieldMeaning
account_countHow many accounts were in the group.
Age, geography, language, interestShares that sum as distributions, not a label on one user.
below_thresholdTrue when the group is too small.
analyzed_atWhen this snapshot was computed. Each run inserts a new snapshot.

The API keeps the newest snapshot for each group label, so the page does not stack three copies of the same run.

6. What to show

Open Audience. Explain the clock first: morning, afternoon, evening in IST, computed from posted_at. Then the group card. If the count is under 50, say so out loud.

One sentence. “This is a keyword sketch of public speakers in the window. It is not an identity record.”

9. Likely questions

QuestionAnswer
How do you know someone is 25 to 34?We do not know. A keyword in a public bio can place the account in a band. Many bios say nothing, so the band is a weak prior.
